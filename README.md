# Trick of the Day

## Ghetto Bird

Ghetto Bird is a Nollie Hardflip Late Bs 180 or Nollie Hardflip Bs Revert; the name was coined after 411 Video released footage of Kareem Campbell nailing it on a bank.

**Invented by:** Unknown

**Year:** Unknown
