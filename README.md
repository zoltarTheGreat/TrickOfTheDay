# Trick of the Day

## Heelflip

Similar to the kickflip, only the board spins toe-side (towards the toes). For a regular skater (left foot in front) the board spins clockwise from a perspective behind the skater. Again, there is a kick as part of the ollie, but unlike the kickflip it is directed forward and outwards away from the rider’s toe side (diagonal), so that the last part of the foot to leave the board is the heel, hence the name.[10] Instances of multiple spins are named according to how many spins are completed.
